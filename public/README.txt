Drop your buddy model here and name it:  What.glb

- It is loaded automatically when the game starts (no code changes needed).
- It should be a skinned/rigged model (bones named like Hips, Spine, Head, UpperArm/Forearm/Hand, Thigh/Shin/Foot ... "Left/Right", "L/R", Mixamo, Blender and Unreal naming all work).
- The model is auto-scaled to ~1.8m tall and placed on the floor.
- The loader maps your skeleton onto the ragdoll; open the browser console to see the list of detected bones ("[Buddy] bones in What.glb").
- If What.glb is missing, the built-in cartoon buddy is used instead.
